# Python Basic Scripts

Repositori ini berisi kumpulan skrip Python dasar yang dibuat untuk latihan pemrograman. Skrip-skrip ini mencakup berbagai topik seperti struktur data, fungsi, loop, input/output file, dan aplikasi sederhana seperti permainan tebak angka serta sistem ujian otomatis.

## Daftar Skrip

- **ATM.py**: Simulasi mesin ATM sederhana.
- **data_structure.py**: Contoh penggunaan struktur data seperti list, tuple, dan dictionary.
- **error_handle.py**: Demonstrasi penanganan error dan exception.
- **file.py**: Operasi dasar pada file (membaca dan menulis).
- **function.py**: Contoh definisi dan penggunaan fungsi.
- **if.py**: Penggunaan pernyataan kondisional (if-else).
- **kalkulator.py**: Kalkulator sederhana untuk operasi matematika.
- **looping.py**: Contoh penggunaan loop (for dan while).
- **nested_loop.py**: Loop bersarang.
- **string_manipulate.py**: Manipulasi string.
- **tebak_angka.py**: Permainan tebak angka dengan menu.
- **variable.py**: Penggunaan variabel dan tipe data dasar.
- **assessment.py**: Aplikasi ujian otomatis yang membaca soal dari file `bank_soal.txt`.
- **bank_soal.txt**: File teks berisi bank soal untuk aplikasi ujian.
- **siswa.txt**: File data siswa (contoh untuk operasi file).

## Persyaratan

- Python 3.x
- Tidak ada dependensi eksternal selain modul standar Python (seperti `random`).

## Cara Menjalankan

1. Clone repositori ini:
   ```
   git clone https://github.com/ahmadfdhl/program-assessment-python.git
   cd python-basic
   ```

2. Jalankan skrip Python mana pun menggunakan interpreter Python:
   ```
   python nama_skrip.py
   ```

   Contoh:
   - Untuk menjalankan permainan tebak angka: `python tebak_angka.py`
   - Untuk menjalankan aplikasi ujian: `python assessment.py`

   Pastikan file `bank_soal.txt` ada di direktori yang sama untuk `assessment.py`.

## Fitur Utama

- **Permainan Tebak Angka**: Pemain menebak angka acak antara 1-100 dalam 10 percobaan.
- **Aplikasi Ujian**: Membuat ujian acak dari bank soal, menampilkan pertanyaan dengan opsi jawaban, dan menghitung skor.
- **Latihan Dasar**: Skrip-skrip lain untuk mempelajari konsep Python dasar.
